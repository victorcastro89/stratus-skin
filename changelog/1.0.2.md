### Added
- `on_primary` / `on_primary_dark` color tokens with auto-derived WCAG AA contrast; applied to buttons, badges, chips, calendar pills, and active nav items
- Button mixin system (`mp-btn-base/primary/secondary/danger/icon`) replacing duplicated declarations across login, calendar, dialogs, smart bar, and editor
- `sidebar_hover_bg` and `sidebar_divider` CSS custom properties added to all color schemes, emitted at runtime from PHP and applied via JS
- `.mp-input()` / `.mp-input-dark()` mixins for a unified input/select style consuming runtime tokens

### Changed
- Static LESS variables replaced with CSS custom properties (`var(--stratus-*)`) across all widget files
- WCAG contrast validation added to `font`, `sidebar_text`, and dark mode secondary color derivation
- Color scheme/font event listeners moved outside `rcmail.init`; trigger queued via `docready`
- `.mp-focus-ring()` now uses `--stratus-focus-ring` runtime token instead of a hardcoded LESS variable
- RC config load order fixed: main config values (e.g. custom color schemes) no longer overwritten by `load_config()`
- Dev environment color scheme definitions consolidated into `docker/config/custom.inc.php`; `roundcube.config.inc.php` removed

### Fixed
- Color scheme and font settings not applying immediately after save
- Move button popover rendering at 0,0; removed `_fixMovePopoverPosition` workaround
- Archive moves now use the same `responseaftermove` cleanup path as regular moves
- Dark mode typography, form borders, toggle knob, and checkbox tracks using wrong color tokens
- Sidebar nav icons misaligned (now flex-centered)
- Mobile layout: task-menu and back-sidebar nav buttons now properly visible on small screens
- TinyMCE toolbar background flickering (FOUC) on editor init
